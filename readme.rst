ModonAi
===========

A discord AI agent that lets you moderate, make changes to your discord server by prompting.

Running the bot
---------------

1. **Install dependencies and run**:
   ```bash
   uv run python main.py
   ```

Changing Code
-------------
- The main entry point is `main.py`.
- Bot configuration and setup are located in `bot/bot.py`.
- Add or modify commands (Cogs) in the `bot/basic_cogs/` directory.
- Use `uv add <package>` to add new dependencies.
